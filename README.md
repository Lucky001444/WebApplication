ช่วยบันทึกข้อมูลการแจ้งซ่อม และติดตามสถานะการปฏิบัติงานได้อย่างเป็นระบบ

## เทคโนโลยีที่ใช้
- **Frontend**: React (Vite) + CSS
- **Backend**: Node.js + Express
- **Database**: MySQL (ผ่าน XAMPP)
- **เครื่องมือเสริม**: Git/GitHub, Axios

---

## ⚙️ การติดตั้งและการรันระบบ (สำหรับนักพัฒนา)

### 1. การตั้งค่าฐานข้อมูล (Database)
1. เปิด XAMPP และ Start เซอร์วิส **Apache** และ **MySQL**
2. ไปที่ `http://localhost/phpmyadmin`
3. สร้างฐานข้อมูลใหม่ชื่อ `repair_db`
4. นำไฟล์ `repair_db.sql` ที่แนบมาในโฟลเดอร์ไป Import เข้าสู่ฐานข้อมูล

### 2. การติดตั้ง Backend
เปิด Command Prompt / Terminal แล้วพิมพ์คำสั่งดังนี้:
```bash
cd backend
npm install
npm run dev

3. การติดตั้ง Frontend
เปิด Command Prompt / Terminal อีก 1 หน้าต่าง แล้วพิมพ์คำสั่งดังนี้:

Bash
cd frontend

npm run dev

📡 รายการ API Endpoints (Backend)
Method  Endpoint           รายละเอียด (Description)

GET     /api/repairs       ดึงข้อมูลรายการแจ้งซ่อมทั้งหมดเรียงจากใหม่ไปเก่า
POST    /api/repairs       เพิ่มรายการแจ้งซ่อมใหม่ (รอดำเนินการ)
PUT     /api/repairs/:id   อัปเดตสถานะการซ่อม (รอดำเนินการ -> กำลังซ่อม -> เสร็จสิ้น)
DELETE  /api/repairs/:id   ลบข้อมูลการแจ้งซ่อมตาม ID ที่ระบุ

หมายเหตุ:
ระบบนี้ใช้พอร์ต 3000 สำหรับ Backend API และพอร์ต 5173 สำหรับหน้าเว็บ Frontend กรุณาตรวจสอบให้แน่ใจว่าไม่มีโปรแกรมอื่นใช้งานพอร์ตเหล่านี้อยู่ก่อนรันระบบ
